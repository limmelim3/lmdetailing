# LM Detailing – ver2

Premium dark/purple redesign of the LM Detailing website.

## Pages
- `index.html` – new homepage
- `index.html.disabled` – previous homepage kept intact/inactive as requested
- `detailing.html`
- `autoservice.html`
- `boka.html`
- `om-oss.html`
- `integritet.html`
- `villkor.html`

## Design
- Black / near-black base with restrained dark-purple accent
- Cinematic AI-generated automotive imagery in `media/ai_*.jpg`
- Purple glow, hover shine and pointer interactions
- Scroll reveal / scale animations retained and refined
- Scroll-to-top button retained
- Responsive mobile navigation retained
- Booking form functionality and vehicle dataset retained
- Shared footer remains injected from `js/main.js`

## Generated media
The BMW imagery in `media/ai_*.jpg` is derived from the AI-generated LM Detailing visual prototypes created for this redesign.

## Notes
The booking form remains a frontend/demo flow until a backend booking system is connected.
